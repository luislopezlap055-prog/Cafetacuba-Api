# Café Tacuba API

Backend del proyecto Café Tacuba desarrollado con NestJS y TypeScript para la materia Programación IV.

## Tecnologías utilizadas

- NestJS
- TypeScript
- Node.js
- Postman

## Módulos

- Usuarios
- Productos
- Categorías
- Pedidos
- Auth

## Instalación

Instalar dependencias:

```bash
npm install
```

Crear un archivo `.env` con:

```env
PORT=4000
API_BASE_URL=http://localhost:4000
```

Ejecutar el proyecto:

```bash
npm run start:dev
```

## Endpoints

Los módulos de Usuarios, Productos, Categorías y Pedidos cuentan con operaciones CRUD mediante GET, POST, PATCH y DELETE.
